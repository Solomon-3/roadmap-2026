this is where sql becomes real

we have users and products(user_id) in our db
relationship => user -> owns -> products

1) INNER JOIN vs LEFT JOIN
Inner join strict
SELECT users.name, products.name
FROM users
INNER JOIN products
ON users.id = products.user_id;   this returns # ONLY users who HAVE products

Left join inclusive
SELECT users.name, products.name
FROM users
LEFT JOIN products
ON users.id = products.user_id;  this returns all users even if they dont have products

SO RUN
week7db=# SELECT users.id, users.name, products.name AS product FROM users INNER JOIN products ON users.id = products.user_id;
week7db=# SELECT users.id, users.name, products.name AS product FROM users LEFT JOIN products ON users.id = products.user_id;

2) COUNT products per user
##########################################                                                             ^
week7db=# SELECT users.name, COUNT(products.id) AS total_products FROM users LEFT JOIN products ON users.id = products.user_id GROUP BY users.name ORDER BY total_products DESC;
   name    | total_products 
-----------+----------------
 salvatore |              2
 Neo       |              1
 Spencer   |              0
 john      |              0
(4 rows)
#######################################
NOTE: if you had used COUNT(*) would result into SPENCER | 1 and this is because COUNT(*) counts rows, not values

3) FILTERING
lets move from show everything to only show what i care about
#####################################
week7db=# SELECT users.name, COUNT(products.id) AS total_products FROM users LEFT JOIN products ON users.id = products.user_id GROUP BY users.name HAVING COUNT(products.id) > 0;
   name    | total_products 
-----------+----------------
 salvatore |              2
 Neo       |              1
(2 rows)
###################################

the key difference is that WHERE -> filter rows                    => filters before grouping 
                           HAVING -> filter aggregated results     => filters after grouping

EXECUTION ORDER
A) FROM / JOIN
B) WHERE        <- filters raw rows
C) GROUP BY     <- creates groups
D) HAVING       <- filters groups
E) SELECT
